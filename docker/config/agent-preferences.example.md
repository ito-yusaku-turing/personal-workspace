# エージェント個人プリファレンス

このファイルは**あなた個人の設定**であり、git 管理外（コンテナ HOME 配下）に置かれている。

- 置き場所: `$HOME/.personal-workspace/agent-preferences.md`
  （ホストでは `$USER_HOME_DIR/.personal-workspace/agent-preferences.md`）
- 仕様: `docs/agent-preferences.md`

## このファイルの使い方

**書くのは「既定から外れたいこと」だけ。初期状態はすべて `特になし` になっている。**

エージェントと作業していて不便を感じたとき（毎回同じ確認をされる、勝手にやってほしくないことをされる）に、**その項目だけ**を書き換える。最初から埋める必要はない。

既定の振る舞い — プリファレンス無しでもエージェントが行うこと、リポジトリのルールで禁止されていること — は `AGENTS.md` と `docs/git-workflow.md` にある。**ここに書き写さない**（二重管理になり、食い違ったときにどちらが正か分からなくなる）。

| 値 | 意味 |
|---|---|
| `特になし` | 既定に従う（**初期値**） |
| `常に許可` | 指示がなくても実行してよい。事後に何をしたか報告する |
| `都度確認` | 実行前に許可を取る |
| `禁止` | 依頼されても実行しない。手順だけ提示する |

**リポジトリのルールで禁止されている操作は、ここで `常に許可` にしても解禁されない。**

## 書き方のルール

**このファイルに書かれている内容はすべて有効な指示として扱われる。**
記入例やメモを残したい場合は **HTML コメントで囲む**こと。エージェントはコメント内を指示として読まない。

```markdown
<!-- これは記入例。エージェントは読み飛ばす -->
```

「例」「サンプル」といった語を本文に添えても**無効にはならない**（有効な指示と機械的に区別できないため）。項目を一時的に外したいときも、削除するかコメントで囲む。

## Git / GitHub 操作

personal-workspace は `main` だけで運用し、セッションを終えるときにエージェントが確認なしで commit と push を行う（リポジトリのルール）。止めたいときは下の `git push` を `都度確認` / `禁止` にする。
マウントした他リポジトリでは、そのリポジトリの `AGENTS.md` 等の規約に従う。そこで禁止されている操作は、ここで許可しても実行されない。

| 操作 | 設定 |
|---|---|
| `git commit`（このリポジトリ） | 特になし |
| `git commit`（マウントした他リポジトリ） | 特になし |
| `git push` | 特になし |
| `gh pr create` | 特になし |
| `gh` でのコメント投稿・レビュー投稿 | 特になし |

## リポジトリの操作

| 操作 | 設定 |
|---|---|
| 依存パッケージの追加・更新（ロックファイルが変わる） | 特になし |
| ファイル・ディレクトリの削除 | 特になし |
| DB へのマイグレーション適用・データ更新 | 特になし |
| マウントした他リポジトリへの書き込み | 特になし |
