description: いま取り組んでいる project / workstream を一覧する（projects/README.md の「取り組み中」の順）
argument-hint: "[絞り込みの文字列] [-f]"
---

personal-workspace の `bin/now.sh` を実行し、出力をそのままコードブロックで見せる。引数: $ARGUMENTS

```bash
/usr/app/personal-workspace/bin/now.sh $ARGUMENTS
```

- 出力を要約したり並べ替えたりしない。
- 「未分類」や「見つかりません」の行があれば、`projects/README.md` の「取り組み中」「待ち・保留」の直し方を一言添える（直すのは頼まれてから）。
